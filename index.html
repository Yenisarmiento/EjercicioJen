Dashboard Demo | Desempeño Comercial + Call Center + Plan de Acción

Carga una base en Excel y el sistema calcula automáticamente productividad, cumplimiento, conversión, contactabilidad, intentos por lead, TMO, ranking, cuartiles y un plan de acción personalizado por coordinador o asesor.

1. Carga de archivo y configuración

El archivo puede traer columnas de ventas y de operación: coordinador, supervisor, leads, matrículas, meta, llamadas, contactos, intentos, TMO, seguimientos y citas. Si alguna variable no existe, se deja como “No disponible”.

2. Fórmula del score comercial-operativo

Score total = 40% resultado comercial + 20% cierre/conversión + 15% contactabilidad + 10% intensidad de gestión + 10% disciplina de seguimiento + 5% calidad de TMO. El score se usa para ranking y cuartiles. El plan de acción se genera con base en las brechas individuales frente a umbrales mínimos y promedios del equipo.
